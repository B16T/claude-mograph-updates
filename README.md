# Claude MoGraph + Claude SFX: updates

This repository only holds the **signed update packages** of the Claude MoGraph and Claude SFX panels for Adobe
Premiere Pro. There is no source code here.

- Installed copies find new versions here by themselves and offer them in the panel (**Update now**).
- Every package is signed by the author: the plugin refuses any file that was not.
- The packages only work with a valid license issued by the author for each computer.
